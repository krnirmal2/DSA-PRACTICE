🚀 My Deloitte Interview Experience — Java Microservice Consultant Role

I recently had the opportunity to interview with Deloitte and wanted to share my experience to help fellow developers
preparing for service-based or Big 4 roles.

The process included:

🔹 2 Technical Rounds
🔹 1 Managerial Round

    ✅ Technical Round 1 (45–60 mins)
    🔹Explained my project architecture, modules, and responsibilities.
    🔹Java: Immutability, mutable & immutable strings, real-world use case.
    🔹Threads: Ways to implement & lifecycle.
    🔹Transaction management and handle rollback in exception.
    🔹Java 8: Streams, lambdas, functional interfaces.
    🔹Sort Employee object using Java 8 & Comparator
    🔹SQL: Find Employee with 3rd highest salary.
    🔹Microservices vs Monolith – advantages and use cases.
    🔹How to create a Microservice and tools used, and how do you monitor one ?
    🔹Coding standards and checklist I follow.
    
    ✅ Technical Round 2 (1 hour)
    🔹JVM vs JRE vs JDK.
    🔹Ways to create String in Java & their storage.
    🔹Interthread communication, wait(), notify() – why they are in Object class not in Thread class.
    🔹Design Patterns used: Singleton implementation, real-time usage.
    🔹Write code for Connection Pool (fixed pool size with acquire/release connection logic).
    🔹Spring Boot: Configure multiple databases (primary & secondary datasource).
    🔹Rollback strategies post commit.
    🔹Project testing & deployment and real production issue debugging.
    
    ✅ Managerial Round (1+ hour)
    🔹Detailed discussion on my project, module ownership, and impact.
    🔹Java Collections: List, Set, Map — why/where I used each.
    🔹Why Set doesn’t allow duplicates, what will happen if I add one.
    🔹Cloud Concepts – explain usage of IAM, EC2, S3
    🔹Exception Handling: Custom exceptions & user-friendly error messages.
    🔹Hands on coding (Notepad): RESTful Person API (id, name, gender as Enum) implement all Layers.
    🔹SQL: Get manager names from Employee table (empId, name, mgrId).
    🔹Logical: You are in a random room out of 100 with 100 switches in a board – what's the most efficient way to turn on the light in your room? (Hint: Binary Search – O(logN))

✅ My Takeaway:
The interviews not only tested my technical depth but also evaluated how I apply my knowledge in real-world scenarios.
I’m thankful for this opportunity and appreciate the experience. Hoping this helps fellow developers preparing for Big
4/service-based roles!

Let’s keep learning and sharing. 🚀
