## 1. Reverse an Array

### Problem Statement
Given an array, reverse its elements so that the first element becomes the last, the second becomes the second last, and so on.

### Brute Force Approach
- **Idea:** Create a new array. Iterate from the last element of the original array to the first, and copy each element into the new array.
- **Steps:**
    1. Initialize an empty result array of the same size.
    2. Loop backwards over the original array.
    3. Place each element into the new array sequentially.

### Optimal Approach
- **Idea:** Reverse the array in place using a two-pointer technique (one pointer at the start and one at the end, swapping elements until they meet).
- **Simplified Code (Java/Pseudo-code):**
  ```java
  public void reverseArray(int[] arr) {
      int left = 0, right = arr.length - 1;
      while (left < right) {
          swap(arr, left, right);  // common utility method for swapping
          left++;
          right--;
      }
  }
  ```
- **Common Utility Method:**
  ```java
  private void swap(int[] arr, int i, int j) {
      int temp = arr[i];
      arr[i] = arr[j];
      arr[j] = temp;
  }
  ```

### Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### Example
- **Input:** [1, 2, 3, 4]
- **Output:** [4, 3, 2, 1]

## 2. Rotate an Array (Left/Right)

### Problem Statement
Rotate the elements of an array either to the left or right by a given number of positions.

### Brute Force Approach
- **Idea:** For each rotation, move elements one position at a time. Repeat the process K times.
- **Steps (for right rotation):**
    1. For each rotation, store the last element.
    2. Shift all other elements one index to the right.
    3. Place the stored element at the beginning.
    4. Repeat K times.

### Optimal Approach
- **Idea:** Use the reversal algorithm. For a left rotation by d positions:
    1. Reverse the first d elements.
    2. Reverse the remaining n–d elements.
    3. Reverse the entire array.
- **Simplified Code (Java/Pseudo-code):**
  ```java
  public void leftRotateArray(int[] arr, int d) {
      int n = arr.length;
      d = d % n;  // handle d > n
      reverse(arr, 0, d - 1);
      reverse(arr, d, n - 1);
      reverse(arr, 0, n - 1);
  }
  
  private void reverse(int[] arr, int start, int end) {
      while (start < end) {
          swap(arr, start, end); // reusing common swap method
          start++;
          end--;
      }
  }
  ```

### Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### Example
- **Input:** [1, 2, 3, 4, 5, 6, 7], d = 2 (left rotation)
- **Output:** [3, 4, 5, 6, 7, 1, 2]

## 3. Shift Elements by K

### Problem Statement
Shift the elements of an array by K positions. (This can be interpreted as a circular shift; if not circular, specify that the “vacant” positions are filled with a default value such as 0.)

### Brute Force Approach
- **Idea (Circular Shift):**
    1. Repeat K times: remove the first (or last) element and append it to the end (or beginning).
- **Steps:**
    - For a left circular shift, remove the first element and append it to the end for K iterations.

### Optimal Approach
- **Idea (Circular Shift):** Use the reversal approach (similar to rotation):
    1. Reverse the first K elements.
    2. Reverse the remaining elements.
    3. Reverse the entire array.
- **Simplified Code (Java/Pseudo-code):**
  ```java
  public void shiftElementsByK(int[] arr, int k) {
      int n = arr.length;
      k = k % n;
      reverse(arr, 0, k - 1);
      reverse(arr, k, n - 1);
      reverse(arr, 0, n - 1);
  }
  ```
  *(For a right shift, adjust the indices accordingly.)*

### Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### Example
- **Input:** [1, 2, 3, 4, 5], k = 2 (left circular shift)
- **Output:** [3, 4, 5, 1, 2]

## 4. Find Min/Max Element

### Problem Statement
Determine the minimum and maximum elements in an array.

### Brute Force Approach
- **Idea:**
    - For minimum: Traverse the array comparing each element to find the smallest.
    - For maximum: Similarly, traverse the array for the largest.
- **Steps:**
    1. Initialize min and max with the first element.
    2. Loop through the array updating min and max accordingly.

### Optimal Approach
- **Idea:** Perform both comparisons in a single pass.
- **Simplified Code (Java/Pseudo-code):**
  ```java
  public int[] findMinMax(int[] arr) {
      int min = arr[0], max = arr[0];
      for (int i = 1; i < arr.length; i++) {
          if (arr[i] < min) {
              min = arr[i];
          } else if (arr[i] > max) {
              max = arr[i];
          }
      }
      return new int[]{min, max};
  }
  ```

### Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### Example
- **Input:** [3, 1, 4, 2]
- **Output:** min = 1, max = 4

## 5. Traverse in Spiral/Zigzag Order

### Problem Statement
Given a 2D array (matrix), traverse its elements in either spiral order or zigzag (alternating direction) order.

### Brute Force Approach
- **Spiral Order:**
    1. Define boundaries (top, bottom, left, right).
    2. Traverse right, then down, then left, and then up.
    3. Adjust boundaries and repeat until all elements are traversed.
- **Zigzag Order:**
    1. Traverse each row.
    2. Alternate the direction of traversal for each row (left-to-right, then right-to-left).

### Optimal Approach
- **Spiral Order:**
    - The optimal solution is essentially the same as the brute-force method but written cleanly using loops and boundary conditions.
- **Simplified Code (Java/Pseudo-code for Spiral):**
  ```java
  public List<Integer> spiralTraverse(int[][] matrix) {
      List<Integer> result = new ArrayList<>();
      int top = 0, bottom = matrix.length - 1;
      int left = 0, right = matrix[0].length - 1;
      while (top <= bottom && left <= right) {
          // Traverse from left to right
          for (int j = left; j <= right; j++) result.add(matrix[top][j]);
          top++;
          // Traverse downwards
          for (int i = top; i <= bottom; i++) result.add(matrix[i][right]);
          right--;
          if (top <= bottom) {
              // Traverse from right to left
              for (int j = right; j >= left; j--) result.add(matrix[bottom][j]);
              bottom--;
          }
          if (left <= right) {
              // Traverse upwards
              for (int i = bottom; i >= top; i--) result.add(matrix[i][left]);
              left++;
          }
      }
      return result;
  }
  ```
- **For Zigzag Order:**
    - You would simply loop row by row and check if the current row is even or odd. For odd rows, reverse the order while adding.
  ```java
  public List<Integer> zigzagTraverse(int[][] matrix) {
      List<Integer> result = new ArrayList<>();
      for (int i = 0; i < matrix.length; i++) {
          if (i % 2 == 0) {  // left-to-right
              for (int j = 0; j < matrix[i].length; j++) result.add(matrix[i][j]);
          } else {  // right-to-left
              for (int j = matrix[i].length - 1; j >= 0; j--) result.add(matrix[i][j]);
          }
      }
      return result;
  }
  ```

### Complexity
- **Time Complexity:** O(m * n) where m = number of rows, n = number of columns
- **Space Complexity:** O(1) extra space (ignoring the output list)

### Example (Spiral Order)
- **Input:**
  ```
  [ [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9] ]
  ```
- **Output (Spiral):** [1, 2, 3, 6, 9, 8, 7, 4, 5]
